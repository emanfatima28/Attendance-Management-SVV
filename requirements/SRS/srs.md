# Software Req Specification

## Introduction
Attendance management system records and manages student attendance digitally

##Functional Requirements
1. User Login
The system shall allow registered users to log in using a valid username and password within 3 seconds.
2. Admin Adds Students
The admin shall be able to add student records with unique roll numbers, and the system shall save the data within 2 seconds.
3. Teacher Marks Attendance
The teacher shall be able to mark attendance for up to 100 students in a single session.
4. System Generates Reports
The system shall generate attendance reports in PDF or Excel format within 5 seconds.

##Non-Functional Requirements
1. System Should Be Fast
The system shall respond to user actions within 3 seconds under normal usage conditions.
2. System Should Be Secure
The system shall encrypt passwords and allow access only to authorized users.
3. System Should Be User Friendly
The system shall provide a simple and easy-to-use interface that a new user can understand within 15 minutes.
