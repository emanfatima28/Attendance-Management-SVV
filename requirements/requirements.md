\# Student Attendance Management System Requirements



\## Functional Requirements



1\. The system shall allow teachers to log in securely.



2\. The system shall allow teachers to mark student attendance.



3\. The system shall store attendance records for each course.



4\. The system shall prevent duplicate attendance entries.



5\. The system shall generate attendance reports.



6\. The system shall allow admin to manage student records.



7\. The system shall maintain course-wise attendance.



8\. The system shall allow viewing attendance percentage.



\---



\## Non-Functional Requirements



1\. The system should be reliable and accurate.



2\. The system should maintain data consistency.



3\. The system should provide secure access to users.



4\. The system should be easy to use.



5\. The system should respond quickly to user actions.



6\. The system should maintain attendance data safely.



\---



\## System Constraints



1\. Attendance can only be marked for registered students.



2\. Attendance cannot be marked twice for the same student on the same date.



3\. Only authorized users can access the system.



4\. Reports must be generated from stored attendance data.
