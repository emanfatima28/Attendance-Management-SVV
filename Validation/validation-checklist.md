# Validation Checklist – Attendance Management System

VC1 – Login page exists and redirects to dashboard on successful authentication  
VC2 – Attendance marking feature available  
VC3 – Database connection configured and reconnects automatically after server restart  
VC4 – Teacher authorization enforced: only users with Teacher role can access attendance marking  
VC5 – Main server file exists  
VC6 – Attendance records are persisted permanently and survive page refresh or server restart  
VC7 – Attendance status displays correct value (Present/Absent) after marking
